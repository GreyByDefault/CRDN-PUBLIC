# Contributing

This public repository is an automatically published source distribution of CRDN.
Development takes place in the owner's private working repository. Public issues
and focused suggestions are welcome; direct changes to this distribution are not
the development workflow.

- Keep CRDN lightweight: Python standard library and plain browser technologies.
- Preserve the four metric groups, read-only behavior and loopback-only API.
- Never include credentials, private server settings or personal data in issues.
- Keep [Russian documentation](README.md) and [English documentation](README.en.md)
  aligned, clearly separating implemented features from future tooling.

The universal installer, update, removal and access recovery tools are planned
for v1.0.0 and are not included in the v0.1.0 pre-release.
